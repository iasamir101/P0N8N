## Oracle Cloud
- Always Free : https://www.oracle.com/cloud/free/
- Astuce : les instances ARM Ampere sont souvent en rupture de capacité ; réessayer à d'autres heures ou changer de région/domaine de disponibilité.
- Ouvrir 80/443 à la fois dans la Security List (console OCI) **et** dans le pare-feu de l'OS (iptables/ufw) : piège classique.
